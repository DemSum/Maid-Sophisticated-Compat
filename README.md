
# Maid Sophisticated Compat

Unofficial compatibility patch for Minecraft 1.21.1 NeoForge.

Adds Touhou Little Maid and MaidsoulKitchen chest type support for Sophisticated Storage and Sophisticated Backpacks block containers.

为 Touhou Little Maid 和 MaidsoulKitchen 添加 Sophisticated Storage 与 Sophisticated Backpacks 方块容器的箱子类型识别支持。
