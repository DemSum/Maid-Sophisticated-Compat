# Changelog / 更新日志

## 0.1.0 - 2026-08-30

### Added / 新增

- Added Touhou Little Maid chest type support for Sophisticated Storage and Sophisticated Backpacks block containers.
- 为 Touhou Little Maid 添加 Sophisticated Storage 与 Sophisticated Backpacks 方块容器的箱子类型识别支持。

- Allows MaidsoulKitchen's Culinary Hub to use the same compatible container recognition when it relies on Touhou Little Maid's chest type system.
- 当 MaidsoulKitchen 的烹饪中枢使用 Touhou Little Maid 的箱子类型系统时，可以识别同样的兼容容器。
